面试怎么讲

  • 秒传用采样 hash 是为了避开 1GB+ 全量 MD5；碰撞风险用「拼进 file size + 分片清单」兜底。
  • 前端 hash 只能当指纹，必须以服务端对收到字节的校验为准。
  • 片太小请求爆炸，太大弱网超时；3～5MB、并发 6 是带宽和连接数的折中。
  • 续传先拉已上传分片，只补缺失。合并失败应返回坏片 index，而不是清掉整文件。
